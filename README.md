# Sourav Kumar Negi — Portfolio

This is a Vite + React + TypeScript portfolio site for Sourav Kumar Negi.

Local dev

```bash
npm install
npm run dev
```

Build

```bash
npm run build
```

Deploy to Vercel

1. Push this repository to GitHub.
2. On Vercel, choose "Import Project" → Connect Git Repository.
3. Set Framework Preset: `Vite` (or leave auto-detect)
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Deploy.

Alternatively install the Vercel CLI and run `vercel` to deploy directly after login.
